Between 22 courses, 1-8 are defined. The 8th is a course called "EVENT". Normally, if a player was to warp to this course, it would be Time Attack B course. 
Events are pre-made scenarios for time attacks. It works on a toggle, and introduces car-specific time attack events; for example an Impreza only Time Attack event. 
It would be ideal to create "enviroment" for enabling custom events, i.e. in the code, there should be a choice of a car to be selected for an event. Then, when the Admin wants to start said event, it should be a toggle (Presumably in the code as well) for enabling/disabling it.
This also comes with requirements, that have to be met - every player must attend in the exact same variant of a car. This leaves two options:

1) The only allowed variant would be a completely stock car - no mods, no exterior, nothing, to ensure balanced rivalry.
2) The event would "spawn" said vehicle with earlier (in the code) set parts settings. Player could only use the car during the event (ex. one week), and the system should not allow the player to use the car for PvP/PvE battles. Player with the best time would end up keeping the car along with some money, which seems like a perfectly balanced scenario.

Both options come with a lot of requirements that have to be met both on the server's and the player's side. Second one seems more suiting though.
